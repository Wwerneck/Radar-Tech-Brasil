# Como contribuir

## Fluxo local

1. Crie uma branch a partir de `main`.
2. Crie o ambiente virtual e instale `requirements.txt`.
3. Execute `python -m pytest -q` antes de abrir um pull request.
4. Não versione dados brutos, credenciais ou arquivos `.env`.

## Padrão de commits

```text
feat: adiciona recurso
fix: corrige comportamento
test: cobre cenário
docs: atualiza documentação
ci: ajusta automação
```

## Pull requests

Explique a alteração, os testes realizados e eventuais impactos na metodologia, no mapeamento CBO ou nos dados publicados.
