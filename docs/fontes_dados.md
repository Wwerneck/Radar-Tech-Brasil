# Fontes de Dados

## Novo CAGED

Fonte oficial: Ministério do Trabalho e Emprego.

Página:
https://www.gov.br/trabalho-e-emprego/pt-br/acesso-a-informacao/acoes-e-programas/programas-projetos-acoes-obras-e-atividades/estatisticas-trabalho/microdados-rais-e-caged

Acesso informado pelo MTE:

```text
ftp://ftp.mtps.gov.br/pdet/microdados/
```

Na versão inicial, os arquivos brutos do Novo CAGED devem ser preservados em:

```text
data/raw/caged/
```

## CBO

Fonte oficial: Ministério do Trabalho e Emprego.

Página:
https://www.gov.br/trabalho-e-emprego/pt-br/assuntos/cbo/servicos/downloads/downloads

Arquivos usados inicialmente:

```text
CBO2002 - Ocupação
CBO2002 - Família
Estrutura CBO
```

Os arquivos brutos da CBO devem ser preservados em:

```text
data/raw/cbo/
```
